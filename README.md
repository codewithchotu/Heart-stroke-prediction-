# ❤️ Heart Disease Prediction Using Machine Learning

A machine learning-powered web application that predicts the risk of heart disease based on patient health parameters. The application uses trained ML models to analyze medical data and provide prediction results through an interactive Streamlit interface.

## 🚀 Live Demo

**Try the application here:**

👉 https://owais-heart-prediction.streamlit.app/

## 📌 Project Overview

Heart disease is one of the leading health concerns worldwide. Early identification of potential risk factors can help people seek timely medical attention.

This project uses machine learning techniques to analyze patient health information and predict the possibility of heart disease.

## ✨ Features

- Predicts potential heart disease risk using machine learning.
- Interactive and user-friendly Streamlit interface.
- Accepts patient health parameters as input.
- Displays prediction results instantly.
- Uses a trained ML model for predictions.
- Accessible online without local installation.

## 🛠️ Technologies Used

- **Python** – Core programming language
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical computations
- **Scikit-learn** – Machine learning algorithms
- **Streamlit** – Web application framework
- **Joblib** – Model serialization and loading
- **Matplotlib / Seaborn** – Data visualization

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/codewithchotu/Heart-stroke-prediction-.git
```

### 2. Navigate to the project directory

```bash
cd Heart-stroke-prediction-
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the environment

**Windows:**
```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal.
